Technical Approach

All development work will be carried out locally before being uploaded to a staging environment for review. Once signed off, the updated site will be deployed live and the DNS records will be updated to point to the new server.

Rather than modifying the current theme directly, I’ll be extending the site with a custom plugin. This keeps your website maintainable and clean, and reduces the risk of future compatibility issues.

Hosting will be moved to Leviathan Studios’ private server environment. This includes:

  • Daily automated backups with 7-day retention
  • Server-level performance monitoring
  • WordPress core and plugin updates
  • Optional Cloudflare DNS and edge caching (requires access)

Admin access is already in place, and once DNS access is available, I’ll handle the migration and go-live process in full.

SEO Considerations

All development work will follow SEO best practices to ensure pages remain crawlable, fast-loading, and structured correctly for search engines.

As part of the rebuild for the “Areas Covered” pages, key on-page elements such as headings, metadata, and alt tags will be retained or improved. Nothing will be hardcoded. Each location-specific page will be fully editable in WordPress.

A technical SEO review will be carried out after deployment using tools such as Screaming Frog or similar. Any flagged issues will be addressed as part of the support time.

While ongoing SEO strategy and copywriting are not included, the technical foundation will be solid and designed to support your PPC and organic visibility efforts.
